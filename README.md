# Dutch Transport Group Slovakia

Static launch site for `dutchtransportgroup.sk`.

## Files

- `index.html` - bilingual one-page site, Slovak first and English switch.
- `styles.css` - responsive styling based on the current Dutch Transport Group brand direction.
- `script.js` - language switching, mobile menu, and mailto quote form.
- `assets/` - local DTG logo, fleet photography, and moving road video copied from the current `.nl` site assets.

## Before Publishing

Update or confirm these details before going live:

- `info@dutchtransportgroup.sk` mailbox or alias.
- Slovakia branch phone number.
- Slovakia branch address, once registered or ready to publish.
- Legal footer text if the Slovak branch has a separate registered company name.
- Point `dutchtransportgroup.eu` either to this same site, a language-selection gateway, or a redirect to `.sk`.

## Deploy

Upload the contents of this folder to the web root for `dutchtransportgroup.sk`.
No build step is required.
